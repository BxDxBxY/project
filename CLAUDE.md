# CLAUDE.md — основной сайт «Diplomatik izohli lugʻat»

Клиент дипломатического толкового словаря для Дипломатической академии при УМЭД
МИД Республики Узбекистан. Next.js 15 (App Router), React 19, TypeScript,
MUI + Tailwind, Tiptap в редакторе статей. Бэкенд — отдельный репозиторий
(Django + DRF) в `../find_uz-main/find_uz/`.

**Полное состояние проекта, история работ и список оставшихся задач —
[`docs/HANDOFF.ru.md`](docs/HANDOFF.ru.md). Читать первым.**

**Разбор каждого дефекта, найденного при запуске в промышленную среду, —
[`docs/ЖУРНАЛ_РАБОТ_2026-11-04.ru.md`](docs/ЖУРНАЛ_РАБОТ_2026-11-04.ru.md).**
Там же зафиксированы ошибки, которые уже совершались, — чтобы не повторять.

На продакшн-сервере каталоги другие: фронтенд `/home/devlugat/frontend`,
бэкенд `/home/devlugat/backend`, эксплуатационные документы
`/home/devlugat/deploy/` (вне git). Запуск — через PM2, а не `npm run dev`.

## Язык

Документация и общение с заказчиком — на русском. Интерфейс сайта — узбекский и
русский, английского интерфейса нет. Код, имена переменных и комментарии в
коде — на английском, как в существующих файлах.

## Команды

```bash
npm run dev          # разработка, порт 3000
npm run build        # сборка
npm start            # запуск собранного
npm run type-check   # tsc --noEmit
npm test             # vitest run
npm run lint
npm run predeploy    # lint + format + type-check + build
```

Бэкенд должен быть поднят первым (порт 8000), иначе данных не будет:
`cd ../find_uz-main/find_uz && uv run uvicorn core.asgi:application --host 0.0.0.0 --port 8000`.

## Устройство

- `src/app/` — страницы. Публичные: `/`, `/dictionary`, `/dictionary/[word]`,
  `/about`, `/contact`, правовые `/privacy`, `/terms`, `/cookies`.
  Редакционные: `/admin/*`.
- `src/app/api/[...path]` — прокси к бэкенду. Реальный адрес бэкенда наружу не
  отдаётся; браузерный код ходит только сюда.
- `src/app/api/auth/session/route.ts` — серверная проверка сессии.
- `src/lib/` — клиенты API, контексты языка и согласия, узбекская сортировка.
- `src/constants/` — переводы, правовые документы, реквизиты организации,
  алфавит.

## Что нельзя ломать

1. **Токены — в cookie с `httpOnly`.** Проверять авторизацию на клиенте через
   `document.cookie` нельзя: так уже ломали редакционную панель. Проверка
   сессии только серверная.
2. **Google Analytics не грузится до согласия на cookie**, reCAPTCHA — до начала
   заполнения формы. Не переносить эти скрипты обратно в корневой layout: это
   требование законодательства о персональных данных.
3. **Реквизиты со значением `TODO` в `src/constants/organization.ts` видимы на
   сайте намеренно.** Не подставлять правдоподобные значения — их заполняет
   юридическая служба.
4. **Сортировка словаря — по официальному узбекскому алфавиту** (диграфы Oʻ, Gʻ,
   Sh, Ch, Ng), `src/lib/uzbekCollation.ts`, покрыта тестами. Не заменять на
   `localeCompare` по умолчанию.
5. **Политика возврата средств не публикуется** — денежных операций нет.
