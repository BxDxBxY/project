## 1. Что это за проект

Электронный дипломатический толковый словарь узбекского языка для
Дипломатической академии при УМЭД МИД Республики Узбекистан. Корпус перенесён
из печатной книги «Diplomatik Lugʻat» (14.08.26). Интерфейс двуязычный —
узбекский и русский, английского интерфейса нет.

Система состоит из бэкенда (Django + DRF, SQLite) и клиента (Next.js 15 / React
19 / TypeScript) с публичным контуром и редакционной панелью.

## 3. Запуск

Полный порядок и сценарий показа — `reports/РЕГЛАМЕНТ_ЗАПУСКА.md`. Коротко:

```bash
# 1. Бэкенд — всегда первым, порт 8000
cd C:\Dev\Dip-academy\find_uz-main\find_uz
uv run uvicorn core.asgi:application --host 0.0.0.0 --port 8000

# 2. Основной сайт, порт 3000 (если сборки нет — сначала npm run build)
cd C:\Dev\Dip-academy\project
npm start

# 3. Вариант 2, порт 3001 (демонстрационный)
cd C:\Dev\Dip-academy\dict-v2
npm start
```

Редакционная панель: `/admin/login`, учётная запись `admin` / `DipAcademy2026`
(одна и та же на обоих сайтах; пароль — демонстрационный, сменить перед выходом
в промышленную среду).

Проверки в `project/`: `npm run type-check`, `npm test`, `npm run lint`,
`npm run predeploy` (прогоняет всё сразу и собирает).

реальный адрес бэкенда скрыт за прокси `/api`, добавлены ограничения частоты

**Август 2026 — стабилизация и замена корпуса.** Починена редакционная панель
(проверка сессии перенесена на сервер — `src/app/api/auth/session/route.ts`),
исправлены валидация пароля, конфигурация адреса бэкенда, флаг `Secure` у cookie
по HTTP, нестабильный `SECRET_KEY` на бэкенде. Корпус заменён и перенесён в
чистую базу текущей схемы (`import_terms.py`), размечен по рубрикам
(`seed_categories.py`). Сделан второй вариант оформления (`dict-v2/`). Полный
разбор — `reports/ЖУРНАЛ_ИЗМЕНЕНИЙ.md`, разделы 2–6.

**Сентябрь 2026 — отчётность и сверка.** Написаны сводный, фронтенд- и
бэкенд-отчёты, регламент запуска, журнал изменений. Доработан
`audit_book_vs_db.py`, проведена сверка с книгой, удалена тестовая запись.

**Октябрь 2026 — правовой аудит и техническая характеристика** (8 неотправленных
коммитов в `project/`):

1. Правовые документы: политика конфиденциальности, условия использования,
   политика cookie — на узбекском и русском (`src/constants/legalDocs.ts`,
   страницы `/privacy`, `/terms`, `/cookies`).
2. Баннер согласия на cookie; Google Analytics грузится **только** после
   согласия (`src/components/analytics/ConsentedAnalytics.tsx`,
   `src/lib/ConsentContext.tsx`).
3. reCAPTCHA грузится только при начале заполнения формы

4. Сортировка словаря переведена на официальный узбекский алфавитный порядок с
   диграфами Oʻ, Gʻ, Sh, Ch, Ng — `src/lib/uzbekCollation.ts`.
5. Доступность: убраны `alert()`, ошибки выводятся блоком с `role="alert"`,

6. Реквизиты организации вынесены в `src/constants/organization.ts`, правовые

## 7. Договорённости, которые легко нарушить по неосторожности

1. **Токены лежат в cookie с `httpOnly`.** Браузерный код их не видит; любая
   проверка авторизации на клиенте через `document.cookie` снова сломает
   редакционную панель. Проверка сессии — только серверная,
   `src/app/api/auth/session/route.ts`.
2. **Google Analytics и reCAPTCHA не возвращать в корневой layout.** GA грузится
   после согласия, reCAPTCHA — при начале заполнения формы. Это требование
   законодательства о персональных данных, а не оптимизация.
3. **Политика возврата средств не публикуется** — денежных операций на сайте
   нет, публиковать нечего. Её сознательно убрали.
4. **Реквизиты `TODO` видимы на сайте намеренно**: отсутствующий реквизит
   безопаснее недостоверного. Не подставлять правдоподобные значения.
5. **Сортировка — по узбекскому алфавиту**, не по кодам символов. Логика в
   `src/lib/uzbekCollation.ts`, покрыта тестами.
6. **Реальный адрес бэкенда скрыт** за прокси `/api` (`src/app/api/[...path]`).
   Не обращаться к бэкенду напрямую из браузерного кода.
7. **Исходную базу `C:\Dev\Dip-academy\db.sqlite3` не изменять** — это источник
   переноса. Рабочая база — `find_uz-main/find_uz/db.sqlite3`, резервные копии
   рядом с ней.
