# Реестр изображений и прав на них

Документ ведётся вручную. Любое новое изображение добавляется в таблицу **до**
публикации на сайте. Если источник и права не подтверждены — изображение не
публикуется.

Статус проверен: 9 сентября 2026 года.

## Используемые на сайте

| Файл | Где используется | Что изображено | Источник | Правовой статус |
|---|---|---|---|---|
| `public/logo2.png` | Шапка сайта, страница 404 | Логотип Дипломатической академии | Организация | **УТОЧНИТЬ:** подтвердить, что логотип принадлежит Академии и его использование согласовано |
| `public/book.png` | Главная страница (варианты 2 и 4) | Обложка печатного издания словаря | Издание Академии | **УТОЧНИТЬ:** подтвердить права на дизайн обложки (автор макета, издательство) |
| `public/mid-uzb2-min.jpg` | Фон шапки сайта | Здание/фотография, связанная с МИД | **НЕИЗВЕСТЕН** | **РИСК:** источник фотографии не задокументирован. Требуется подтвердить авторство и разрешение либо заменить на собственный снимок |

## Хранятся в репозитории, но не используются

| Файл | Комментарий | Рекомендация |
|---|---|---|
| `public/logo.png` (3,3 МБ), `public/logo-min.png` (1,1 МБ) | Исходники логотипа 2084×2084 | Убрать из `public/` (они отдаются веб-сервером). Хранить в дизайн-архиве |
| `public/mid-uzb2.jpg` | Несжатая версия фонового фото | Тот же вопрос по источнику, что и у `mid-uzb2-min.jpg` |
| `public/diplomatic-academy.jpg` | Файл с расширением `.jpg`, но фактически PNG (884 КБ) | Источник не задокументирован. Удалить либо подтвердить права |
| `public/partner-1..4.png` | Логотипы сторонних организаций-партнёров | **ВЫСОКИЙ РИСК:** чужие товарные знаки. Публиковать только с письменного согласия каждой организации |

## Правила для новых изображений

1. Допускаются только: собственные материалы Академии, изображения с
   документально подтверждённой лицензией, либо материалы из общественного
   достояния с указанием источника.
2. Государственные символы (герб, флаг) используются только в порядке,
   установленном законодательством Республики Узбекистан.
3. Фотографии людей публикуются только с их согласия.
4. Для каждого файла в таблицу вносятся: источник (URL или автор), тип лицензии,
   дата получения прав, ссылка на подтверждающий документ.
5. Каждое содержательное изображение получает атрибут `alt` с описанием;
   декоративные изображения помечаются `alt=""` и `aria-hidden="true"`.
